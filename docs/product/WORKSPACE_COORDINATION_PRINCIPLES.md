# Workspace Coordination 원칙

제품은 사용 가능한 evidence를 바탕으로 proposal, concern, blocker, decision, unresolved question, next action을 요약합니다.

제품은 teammate를 순위화하거나, productivity score를 매기거나, blame summary를 생성하거나, evidence를 넘어 intent를 추론하거나, fixture에 private customer data 또는 employee private data를 사용해서는 안 됩니다.
